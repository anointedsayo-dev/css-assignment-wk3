# First HTML & CSS Website

## Project Overview

This project is a beginner-friendly website I created as part of my journey into Front-End Development.

The website was built using HTML and CSS, with a focus on practicing webpage structure, styling, and responsive design.

## Technologies Used

- HTML5 – Used to structure the webpage and its content.
- CSS3 – Used for styling, layout, colors, typography, and visual design.

## Features

- Clean and simple user interface
- Responsive webpage structure
- Organized HTML structure
- Custom CSS styling
- Beginner-friendly design
- Separate HTML and CSS files

## What I Learned

While working on this project, I practiced:

- Creating webpages with HTML
- Using semantic HTML elements
- Connecting CSS to HTML
- Styling text, buttons, and sections
- Working with margins and padding
- Understanding webpage layouts
- Organizing frontend project files
- Using Git and GitHub to store and manage my project
